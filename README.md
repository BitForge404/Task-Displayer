# Task-Displayer
Release v1.3
Task Displayer is now available to download in a .zip file with a setup.exe that takes care of any setup processes. Execute the setup.exe and then the Task Displayer Application should be fully usable.

Task Displayer is an App that allows you to enter Tasks with priority labels from any device from anywhere. These Tasks will the pop up on the host device. To complete the tasks a Work order number has to be provided. The complete Task is stored in a History.
